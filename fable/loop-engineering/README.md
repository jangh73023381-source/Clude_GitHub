# 루프 엔지니어링 (loop-engineering)

단기 추천 ETF **상위 5종**이 "전체 ETF(전일 종가 1만원 이상) 익일 종가 상승률 순위에서 상위 10%"에
**5종 전부** 드는지 채점하고, 미달 시 **선정 방법(로직) 자체를 최대 5회 반복 개선·검증**해 진화시키는
자기개선 루프 스킬입니다.

## 핵심 원칙
- 개선 대상은 **선정 방법**이지, 결과(상승률)를 보고 종목을 콕 집는 것이 아닙니다(룩어헤드 금지).
- **불가항력**(선정 시점 예측 불가한 돌발 변수) 미달은 방법을 바꾸지 않고 수용합니다.
- 추천 종목은 **현물 ETF만**(레버리지·인버스 제외). 비교 유니버스에는 포함될 수 있습니다.
- 개선안은 일반 규칙으로 표현하고, 다른 과거일 1개에서 비악화를 교차 확인합니다(과적합 방지).

## 워크플로우 (6단계)
1. 대상 수집 — 최근 단기 추천 ETF 5종 + 현 분석 방법 로드
2. 목표 채점 — 전체 ETF 순위·상위10% 컷오프·5종 적중 판정
3. 분석 — 달성 시 유지 / 미달 시 불가항력 vs 학습가능 분류·개선안 도출
4. 검증 루프 — 방법 업데이트 후 전날로 돌아가 재산출·재채점(최대 5회)
5. 완료·저장 — 업데이트 불필요 시 방법 확정 저장
6. 결과물 — 현 추천 순위 + 신규 방법 추천 순위 + method diff + 루프 로그
