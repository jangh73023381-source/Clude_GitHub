# 루프 엔지니어링 실행 로그

각 실행과 루프 회차를 기록한다. 채점·개선·검증의 추적성을 남겨 동일 실수 반복을 막고,
방법 버전의 채택 근거를 보존한다.

## 기록 형식

```
## YYYY-MM-DD 실행 (평가 대상일: 추천일 = D, 채점 익일 = D+1)
- 유니버스: N종(≥10,000원), 상위10% 컷오프 = 상위 K위
- 현 방법 버전: vX.Y

### 채점 (A: 현 추천 5종)
| 종목 | 코드 | 전날종가 | 익일종가 | 상승률 | 전체순위 | 백분위 | 상위10% |
|------|------|---------|---------|--------|---------|--------|---------|
...
- 적중: m/5  → 달성여부

### 분석
- 미적중 종목별 사유: [불가항력] 또는 [학습가능: 코드]
- 학습가능 개선안: ...

### 검증 루프
- 1회차: 방법 vX.(Y+1) 적용 → 신규 5종 / 적중 m/5 / 잔여 사유
- 2회차: ...
- (최대 5회)

### 결과
- 최종 채택 방법 버전: vX.Z
- 교차일 비악화 확인: YYYY-MM-DD 적용 결과
- 완료/미완료(추가 개선 필요)
```
