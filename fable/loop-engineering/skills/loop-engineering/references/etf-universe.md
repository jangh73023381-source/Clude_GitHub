# ETF 유니버스 구성·종가 수집 절차

목표: 평가 대상일 **전날 종가 10,000원 이상**인 **전체 한국 상장 ETF**(레버리지·인버스 포함, 채점 전용)를
모아 익일 상승률 순위를 매긴다.

## 1. 유니버스 목록 유지 (`etf_universe.csv`)

스킬 폴더에 `etf_universe.csv`를 유지한다. 컬럼: `code,name,type`

- `code`: 6자리 종목코드 (예: 069500)
- `name`: ETF명
- `type`: `현물` / `레버리지` / `인버스` (추천 후보 필터링·표기에 사용. 비교 순위엔 전부 포함)

목록 갱신 방법(택1):
- 사용자가 보유한 ETF 리스트 파일(예: `ETF.xlsx`, korean-etf-analyzer 입력)을 불러와 code·name·type을 추출.
- 네이버 금융 ETF 목록 페이지를 Claude in Chrome으로 수집해 코드·명을 갱신.
- 최소 운영: 데일리브리핑에서 다루는 ETF + 주요 지수·섹터·테마 ETF로 시드하고, 실행마다 누락 ETF를 추가.

> 전체 상장 ETF는 수백 종이다. 목록이 클수록 상위 10% 컷오프가 정확해진다. 목록 규모(N)는 보고서에
> 반드시 명시한다(예: "유니버스 480종 기준 상위 10% = 상위 48위").

## 2. 종가 수집 (yfinance MCP)

- 샌드박스 직접 네트워크(yfinance 파이썬)는 **403으로 차단**된다. 한국 ETF는 반드시
  **yfinance MCP `yfinance_get_price_history`** (코스피 `.KS`, 코스닥 `.KQ`)로 조회한다.
- 각 코드의 **전날 종가(C0)**와 **익일 종가(C1)**를 수집한다(period=5d로 받아 해당 두 날짜 추출).
- 전날 종가 < 10,000원인 종목은 유니버스에서 제외한다.
- 조회 실패 종목은 1회 재시도, 계속 실패면 해당 종목을 제외하고 보고서에 누락을 명시한다.
- 수집 결과를 `prices_YYYY-MM-DD.csv`로 저장: `code,name,type,prev_close,next_close`.

## 3. 순위·컷오프 산출

`scripts/rank_etf.py`에 가격 CSV와 추천 5종 코드를 넘겨 실행한다:

```
python3 rank_etf.py --prices prices_2026-06-15.csv --picks 091160,390390,466920,449450,102970
```

출력: 전 종목 익일 상승률 순위, 상위 10% 컷오프(상위 K위), 추천 5종 각 순위·백분위·적중 여부, 5종 전부 적중 여부.
