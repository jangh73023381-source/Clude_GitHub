## ⑧ 해석 기록
1. **백분위**: 선정일 D에 해당 시계 mom_k가 산출 가능한 okH 종목(종가 존재) 안에서 평균 순위로 (rank−1)/(n−1)을 계산했다(0~1). 점수는 가용 시계 백분위의 평균이며, 대상은 mom150이 산출 가능한 종목으로 제한했다. 상위 5종을 뽑고, 동점이면 mom150 내림차순으로 정했다.
2. **P2의 교체 수**: 명세 문언 그대로 "목표집합"의 전일 대비 신규 편입 종목 수의 일평균으로 계산했다. 실제 보유(CB 밴드 체결)가 아니다. 목표집합은 밴드와 무관하므로 이것이 문언에 맞는 해석이다.
3. **P3 분해**: 탈락일 D(전일 목표에 있었고 D 목표에 없음)마다 다음 두 항을 구했다.
   - 당일 항 = logC_D − logC_{D−5}
   - 기준일 항 = logC_{D−150} − logC_{D−155}
   - 비중 = |기준일 항| / (|기준일 항| + |당일 항|)
   Rule H 배제로 인한 탈락도 포함했다. 제외한 수치도 같이 적었고, 결론은 같다.
4. mom150 기준 목표는 공유 엔진 `targets(MOM[150], 250)`(okH, Rule MM과 같은 유니버스)으로 만들었다. VMX 슬리브와 같은 목표집합이다.
5. 종결 판정 근거는 P2 하나다. P1·P3가 통과했다는 사실이 이 종결을 뒤집지 않는다(명세 OR 규칙).
