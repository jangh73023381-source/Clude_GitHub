세 파일에서 **당신의 가설 3개에 대한 부분을 전부** 읽어라.

각 가설마다:
1. **수용 / 부분 수용 / 반박** 중 하나를 선언하고, 비평의 가장 강한 논점에 직접 답하라(회피 금지). 반박하려면 논리·수식·기존 실측 수치 근거를 댄다.
2. 비평이 옳다면 **철회**하라. 철회는 부끄러운 일이 아니다 — 다중검정 예산(이번 세션 가설 5~6개, 변형 ≤25개)을 아끼는 것이 모두의 이익이다.
3. 계속 방어하는 가설은 **최종 사전등록 명세**를 쓴다:
   - 기본 파라미터 1개 + R1 인접값 ≤3개 (비평가 요구 반영)
   - 1차 지표(단기는 OO, L1·OOx 병기 / 중기는 실제 집행 틀) 와 합격 기준(수치)
   - 필수 대조군(비평가가 요구한 것 포함)과 각각의 기각 조건
   - 선행 점검(성과를 보기 전에 끝낼 수 있는 전제 검사)과 그 종결 조건
4. 백테스트는 여전히 돌리지 않는다(사전등록을 오염시키지 않기 위해).
