## 비평가 핵심 실측(전제로 유지)
- 7년 OO LV−MOM 일별 차 SE 0.035%p/일 → t=2 검출에 연 ~17%p, Bonferroni면 ~28%p 차이 필요. **수익 개선으로 관문을 넘을 사전 근거가 있는 가설은 없다.**
- Sharpe 차 SE ≈ 0.18(상관 0.95) → 판정은 블록 부트스트랩(블록 20, 2,000회) 90% CI.
- 유효 시도 100~850이면 운만으로 t≈2.6~3.2 기대(Deflated Sharpe).
- LV 픽 중 20일 거래대금 1억 미만 17.1%·5억 미만 36.4%, 정적 시가 12.9%(KODEX200 2.3%) — 가상 체결이 fold1·2에 몰림. 최근 1년은 정상.
- 데이터 이상치: 441640 KODEX 미국배당커버드콜액티브 20240405 −20.56%(분할·분배 확인 필요).
