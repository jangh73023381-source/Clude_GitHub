# 국면별 방법 전환 검정 — 사전 고정 설계 (2026-10-22 21:20 KST, 실행 전 작성)
- 국면: 선정일 D 종가 기준 KODEX200(069500) < MA60 → BEAR, 아니면 BULL. 경계 최적화 금지. (MA120 은 강건성 보고용, 선택에 쓰지 않음)
- 단기([6-1], 1일 회전, 지표 A·OO): 기준 LV. 후보
  S1 BULL=MOM(mom20 상위5) / BEAR=LV
  S2 BULL=LV / BEAR=전 유니버스 σ20 최저 5(모멘텀 무관 최소변동)
  S3 BULL=LV / BEAR=mom60 pool30→σ20 하위5 (느린 모멘텀)
  E1 LV + BEAR 비중 50%(나머지 현금 0%) · E2 LV + BEAR 현금
- 중기([6-3], 20일 겹침 트랜치): 기준 mom150(Rule MM). 후보
  S4 BULL=mom150 / BEAR=MLV · E3 mom150 + BEAR 트랜치 50% · (참고) MLV 상시
- 통과 조건(전부): ① Sharpe 기준 초과 ② BULL·BEAR 각 국면 일평균이 기준 이상(국면별 비열위) ③ 3분할 fold 3/3 ④ R5 상위3일 제거 후 일별 차 ≥0 ⑤ 국면 라벨 원형 시차이동(≥250일) 200회 대조군 대비 Sharpe p<0.05
