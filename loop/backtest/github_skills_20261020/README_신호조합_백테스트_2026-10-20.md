질문: 단독으로는 기각된 방법도 2개 이상 조합하면 달라지는가.
데이터: 개별종목 7.7년 일봉(px_daily, 현 상장사 → 생존편의) + 분기 재무(_factor_panel, PIT). 검정 구간 2020-06~2026-08.
설계: 20거래일 보유·리밸런싱(시작 오프셋 0/5/10/15), 기준 = 같은 날 그 조합의 신호가 모두 있는 유동 종목 동일가중.
방법 RA = 순위 평균 상위 20%, AND = 각 신호 상위 30% 교집합. **앞 절반(~2023-06)으로 고르고 뒤 절반(2023-07~)에서 확인.**

## 1. 조합은 '종목 고르기'를 실제로 개선한다
- 단일 최강: NH +1.09%p/20일(t 3.39), PVC +0.72(t 3.91).
- 앞 절반 상위 2개 조합 8개 → 뒤 절반 전부 양수(t 2.3~5.4). 3개 조합 8개 → 7개 양수.
- NH+PVC 순위평균: +1.16(t 4.40), fold 0.53/1.19/1.74, 상위5% 제거 +0.92, 뒤 절반 +1.75(t 4.22) — 두 단일보다 뒤 절반에서 높다.
- 사전 지정 '11개 전부': +0.85(t 3.23)이나 fold1 −0.08 — 나쁜 신호(REV·TV)가 섞이면 희석된다.
- **앞 절반에서 양수였던 5개(NH·PVC·TT·OPG·EY) 순위평균**: 유동 전체 +1.05(t 3.46), 대형 200 풀 +2.37(t 3.93, fold 0.62/3.84/2.63, 앞 +1.65 · 뒤 +2.88, R5 +1.76).
