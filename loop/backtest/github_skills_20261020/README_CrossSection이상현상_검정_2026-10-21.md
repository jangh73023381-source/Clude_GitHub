저장소: github.com/OpenSourceAP/CrossSection — 학술 이상현상 331개의 정의·부호(SignalDoc.csv). 우리 데이터로 계산 가능하고 **기존에 검정하지 않은 것**만 골랐다
(모멘텀·신고가·단기반전·저σ·PBR·PSR·EP·Piotroski·거래대금 등 기검정은 제외).
설계: 개별주 7.7년 일봉 + 분기 재무(PIT), 월(20거래일) 1회 신호 방향 상위 10% 동일가중 20일 보유, 기준 = 같은 날 유동 유니버스(신호 보유 종목) 동일가중.
오프셋 0·10, 앞(~2023-06)/뒤 분리. 근사: 1개월=21거래일, 시장=유동 동일가중, FF3→시장 1요인, EPS→영업이익, 4분기=연간−1~3분기.
다중검정: 31개 → Bonferroni 양측 0.05 ≈ |t|≥3.0.
