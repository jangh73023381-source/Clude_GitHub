## 1. 블랙록 사례 — "잘 맞는다"는 평판의 실측

사용자 질의("블랙록 전망이 잘 맞는다던데")에 대한 검증. 한국 관련 콜은 날짜가 특정된다.

| 블랙록 콜 | 직전 20일 | 당일 코스피 | 직후 20일 | 직후 60일 | 현재까지 |
|---|---|---|---|---|---|
| 2026-04-16 신흥국 비중확대 상향 | +8.0% | 6,226 | **+20.7%** | +17.0% | +12.6% |
| 2026-06-30 비중확대→중립 하향 | -3.5% | 8,476 | **-33.2%** | — | -17.3% |
| 2026-09-14 중립→비중확대 상향 | -4.2% | 6,684 | (6일 +4.8%) | — | +4.8% |

**세 콜 모두 방향이 맞았다.** 특히 6/30 하향 직후 코스피는 8,476 → 5,594(-34.0%)로 폭락했다.
평판에 근거가 있다는 점은 인정하고 시작한다. 그러나:

- **6/30 하향은 6/26 급락(-5.81%, 서킷브레이커) 의 2거래일 뒤다.** 급락을 예측한 것이 아니라
  급락을 보고 내렸다. **우리 시스템은 6/26 당일 급락 게이트로 알았고, 6/27 에 규칙을 개정했다
  (fable CLAUDE.md 8번).** 블랙록보다 4거래일 빨랐고 그 4일이 -5.81% 구간이었다.
- **9/14 상향은 7/30 저점(5,594)에서 이미 +19.5% 오른 뒤다.** 바닥을 잡은 것이 아니다.
- 4/16 상향도 직전 20일 +8.0% 오른 뒤다.

**세 콜 전부 움직임이 시작된 뒤에 나왔다 — 예측이 아니라 추세 확인이다.**
[[loop-trade-data-sector-rotation]] 의 k=0(동시), [[attention-search-weight-rejected]] 의
검색량 3~4일 후행과 같은 자리다.

**표본 3건**이고, 그마저 **결과를 알고 고른 3건**이다(사후 선택). 블랙록은 주간 코멘터리를
매주 내고 자산군 수십 개에 뷰를 매긴다. 전수로 세면 연 3~4회 × 7년 ≈ 25건으로,
「IB전망 검토」 §7 의 표본 산술과 같은 벽에 부딪힌다.

**해상도 부재**: 2026 Q4 Global Outlook 실측 — 자산군이 미국 주식 / 신흥국 주식 / 단기채 /
장기국채 수준이고 **한국은 국가별로 분리되지 않는다.** 섹터 해상도는 아예 없다.

## 3. KRX ETF 설정/환매 — 패널 2년 연장 후 기각 확정

국내 ETF 상장좌수(`list_shrs`) 변화 = 설정(+)/환매(-) = **기관이 실제로 돈을 넣고 뺀 기록**.
ETF 유니버스가 실매수 대상과 일치해 이 축이 가장 유망했다.

**신호**: D-1 상장좌수 변화율(KRX 는 D+1 공개이므로 §4-6 실전 조달 가능한 형태는 이것뿐).
**지표**: 익일(D종가→D+1종가) 전체 ETF 동일가중 대비 초과수익.

### 3-1. 1차(114일) → 2차(450일) — 표본을 늘리자 사라졌다

패널을 `krx_api` 로 **114일 → 536거래일(2024-09-02~2026-09-21, 548,071행, 1,265종)** 확장했다.
`universe_filters.eligible` 적용 후 관측 **97,694건 · 450거래일 · 1,048종**.

| 관문 | 114일(1차) | **450일(2차)** |
|---|---|---|
| 전체 Q5-Q1 | +0.088%p (t=+1.78) | **-0.007%p (t=-0.35)**, rho -0.0007 (p=0.826) |
| R2 fold | -0.126 / +0.288 / +0.135 | +0.016 / **-0.067(t=-2.46)** / +0.020 |
| R5 꼬리 | 상위 3일 80.1%, 5일 제거 시 부호 반전 | 평균 +0.0016 · **중앙 -0.031 · 승률 45.6%** · **상위 1일 제거만으로 음수** |
| 대조군(셔플) | p=0.070 (구간 안) | **p=0.695** — 완전히 잡음 |
| 모멘텀 통제 | 통과(rho 불변) | 통과(-0.0007 → -0.0008) — 이제 통제할 신호가 없다 |

**★ §4-5 의 직접 실증.** "2년 604일 미만으로는 승격도 기각도 확정하지 않는다"가 이번엔
**기각 방향으로** 작동했다. 114일의 +0.088%p(t=1.78)는 표본이 만든 허상이었다.
**얇은 표본의 양수를 '유망'으로 올리지 말 것.**

### 3-2. ★ 부수 발견 — 효과의 60%가 레버리지·인버스에서 왔다

유니버스 필터를 걸기 **전**에는 Q5-Q1 **+0.220%p(t=3.12)** 였고, `eligible` 적용 후 +0.088%p 로
주저앉았다(1,181 → 1,011종). Rule EG 에서 확인한 **"저유동·파생 ETF 가 거래량 게이트를 무력화한다"**
와 같은 구조다. → **앞으로 ETF 횡단면 검정은 `universe_filters.eligible` 적용을 전제로 한다.**

### 3-3. 데이터 사고 1건 — 발견·복구 완료

`collect_etf_extend.py` 초판이 KRX API 필드명을 `ISU_SRT_CD`·`NETASST_TOTAMT` 로 잘못 써
**code·netasset 이 빈 420,683행이 패널에 유입**됐다(중복 (date,code) 420,261건). 즉시 발견해
손상본을 `.bad_20260922` 로 보존하고 빈 code 행 제거로 원상복구한 뒤, 기존 수집기
(`collect_krx_etf_idx_20260818.py`)의 올바른 필드명(`ISU_CD`·`INVSTASST_NETASST_TOTAMT`)으로
재수집했다. 복구 후 **중복 0 · 빈 code 0**, `integrity_check.py` **OK 23 · 경고 0 · 오류 0**.
**재발 방지**: 같은 API 의 필드 매핑을 두 곳에 따로 적지 말 것 — 새 수집기는 기존 수집기의

## 4. DART 글로벌 운용사 대량보유 공시 — 7년 검정 후 기각

글로벌 운용사의 **한국 종목 단위** 포지션이고, 공시 의무라 **시계열 재구성이 완전히 가능**하며
(13F 45일 대비) **5영업일 보고**다. 이 프로젝트에서 검정된 적이 없어 이번에 전수 수집했다.

### 4-1. 수집 — 7년 전수

```
지분공시(pblntf_ty=D) 전체   201,530건  (2019-04-01 ~ 2026-09-22, 90개월)
  → 대량보유상황보고서        83,004건
  → 글로벌 운용사 보고자       1,709건  (2.1%) · 310종목
연도별  2019:165  2020:294  2021:237  2022:176  2023:204  2024:186  2025:225  2026:222   ← 고르게 분포
보고자  피델리티 525 · 베어링 194 · Morgan Stanley 158 · BlackRock 115 · Credit Suisse 104 ·
        FIL 102 · Capital Group 86 · JPMorgan AM 47 · GIC 44 · UBS 35 · Norges Bank 32 ...
```

보유비율 증감(`majorstock.json`)은 **최근 2년치만** 제공돼 491건에만 붙는다.
그래서 **7년 이벤트(방향 무관)** 와 **2년 방향별** 두 갈래로 검정했다.

### 4-2. 겉보기에는 유의하다

```
7년 이벤트(방향 무관), 전종목 동일가중 대비 초과
  D+1  +0.115% (t=1.52)   D+5  +0.326% (t=1.98)   D+10 +0.798% (t=3.28)
  D+20 +1.080% (t=3.15)   D+40 +1.414% (t=2.59)     ← 기간에 따라 단조 증가
```

### 4-3. 그러나 네 관문에서 전부 무너진다

**① 방향에 정보가 없다 (가장 결정적)**
```
2년 491건 (증가 262 · 감소 220 · 변동없음 9)
  증가(+)  D+1 +0.88%(t+3.33)  D+5 +0.99%  D+10 +1.67%  D+20 +2.08%  D+40 +3.13%
  감소(-)  D+1 -0.68%(t-2.97)  D+5 +1.24%  D+10 +2.46%  D+20 +3.32%  D+40 +6.28%
  증가-감소  D+5 -0.25%p (t-0.35, p=0.728)   D+20 -1.24%p (t-0.76, p=0.446)
```
**판 종목이 산 종목보다 더 올랐다.** 방향이 맞는 것은 D+1 뿐이고(공시 당일 반응),
D+5 부터 역전된다. "글로벌 운용사가 담은 종목을 따라 산다"는 전제가 데이터로 지지되지 않는다.

**② R2 연도 fold 실패** — 2023년 **-2.442% (t=-2.66)** 유의 음수. 8년 중 1년 실패.
```
2019 +0.520 · 2020 +1.290 · 2021 +0.483 · 2022 +2.176 · 2023 -2.442 ·
2024 +1.063 · 2025 +2.782 · 2026 +2.706   (D+20 초과 %)
```

**③ R5 실패** — 평균 +1.080% 인데 **중앙 -0.548% · 승률 48.1%**. 상위 10건이 이득의 46.3%.
(다만 상위 3건 제거 후에도 +0.856 로 부호는 유지된다 — R5 중 부호 기준만 통과.)

**④ ★ 지속형 무작위 대조군 미통과 — 이번 회차 최대 발견**
```
같은 종목, 무작위 날짜 300회 (D+20 초과)
  귀무 평균 +0.542%   sd 0.336   90% 구간 [+0.014, +1.105]
  관측 +1.080%  →  구간 안.  경험적 p(귀무 ≥ 관측) = 0.060
```
**귀무가 0이 아니다.** 글로벌 운용사가 5% 이상 보유한 종목군은 **아무 날짜나 잡아도 20일에
+0.54% 초과**한다. 즉 t=3.15 의 절반은 이벤트가 아니라 **유니버스(우량주 편향·생존편의)의 값**이다.
[[actually-rebuttal-event-closed]] 에서 "셔플 귀무 평균이 0이 아니다"를 배운 것과 같은 함정이
**종목 선택 편향**에서 재현됐다. → **이벤트 축은 반드시 같은 유니버스의 무작위 시점과 비교할 것.**

### 4-4. 실무 부적합 — 통과했어도 실을 자리가 없다

- **대상이 소형주다** — 코스모로보틱스·인바디·바텍·미창석유공업·하이록코리아·테크윙·SOOP.
  BlackRock 115건도 삼성전자·SK하이닉스가 아니라 HLB·LG디스플레이 쪽이다.
  **ETF 유니버스(트랙 A·Rule CB)와도, 트랙 D 187종과도 겹치지 않는다.**
- **거의 전부 '약식' = 단순투자목적**(패시브). 액티브 뷰가 아니라 지수 추종에 따른 기계적 변동이며,
  공시는 5% 선을 넘나들거나 1%p 변동할 때만 나온다.
- 개별종목 추천은 **7절 폐지(2026-09-05)** 로 사라졌다.

## 5. 이미 쓰고 있는 것 — 외국인·기관 순매수

글로벌 운용사가 한국 주식을 실제로 사고팔면 **그날 외국인 순매수로 나타난다.** 이것이
가장 빠르고(D+0 장마감) 가장 해상도 높은(종목 단위) 포지션 데이터이며, **이미 보유·사용 중**이다.

- 데이터: 키움 ka10045 · `backtest/flow_2y.csv`(96,071행, 2024-02~2026-07, 기관·외국인 순매수 + 외국인한도소진율)
- 용도: **Rule EG v1.2 수급 게이트** — 기관+외국인 5거래일 누적 순매수 > 0 인 신호를 우선 매수.
  2년 1,088건: 통과 +9.15%(승률 74.6%) vs 미달 +4.74%, t=2.43, 플라시보 p=0.027. **잠정**(2년 표본).
- **외국인 단독은 무효**(5일 누적 fold 미달). 기관 또는 합산만 유효하다는 것이 실측이다 —
  "외국인(=글로벌 운용사)만 따라가면 된다"는 통념과 반대다.
- **선정 축으로 재개방 금지**: Rule V 30변형(2026-07-10) · Rule W(ka10045 결합, 07-10) ·
  비가격축 수급 계열(07-29) 전부 기각 이력. 게이트 용도로만 유지한다.

## 6. 열지 않기로 한 것 / 재시도 금지

- **13F·다크풀·유료 플로우 구매** — 2026-09-08 판정 유지. 지연 구조상 알파 불가가 확정적이다.
- **ETF 상장좌수·순자산 변화를 익일 수익률 신호로 쓰는 모든 변형** — §3. 450일에서 부호가 없다.
  되살리려면 **fold1 부호와 R5 중앙값을 먼저 양수로** 보일 것.
- **대량보유 공시 발생을 이벤트 신호로 쓰는 축** — §4. 되살리려면 **무작위 시점 귀무(+0.542%)를
  넘는 초과**와 **방향 스프레드 양수**를 먼저 보일 것.
- **수급을 선정 축으로 전환** — §5. 기각 이력 3건(Rule V 30변형 · Rule W · 비가격축 계열).
- **블랙록 등 특정 운용사의 뷰를 게이트로 신설** — §1. 우리 급락 게이트보다 4거래일 느리다.
- **구간 경계·보유기간 최적화** — 하는 순간 알파 축이 되어 R1~R5 + 지속형 무작위 대조군을
  전부 통과해야 한다.

## 7. 한계 — 반드시 함께 적을 것

1. **§3 의 450거래일은 2024-09~2026-09 구간**이고, 7년 패널(`panel_ohlc_long.csv`)이 아니다.
   이 구간에 2020 코로나·2022 베어가 없다 — §4-5 기준으로는 여전히 '2년급' 표본이다.
   다만 114일 → 450일에서 신호가 **커지지 않고 사라졌으므로** 기각 방향의 결론은 유지한다.
2. **§4 의 방향별 검정은 2년(491건)뿐**이다. `majorstock.json` 이 최근 2년치만 준다.
   7년 이벤트 축(1,709건)은 방향 정보가 없는 대신 표본이 크다 — 두 갈래를 각각 읽어야 한다.
3. **§4 의 보고자 매칭은 정규식**이라 한글 음차 표기 변형에서 누락이 있을 수 있다.
   실제 글로벌 운용사 공시는 1,709건보다 많을 수 있으며, 그 경우 §4-1 의 연도별 분포는 하한이다.
4. **§1 의 블랙록 3콜은 사후 선택된 3건**이며 성적 평가가 아니다. 전수 평가는 하지 않았다.
5. **외국인 순매수는 글로벌 운용사만이 아니다** — 헤지펀드·차익거래·ETF LP 가 섞여 있고
   분해할 경로가 없다. §5 의 "이미 쓰고 있다"는 그 혼합값을 쓴다는 뜻이다.
6. §3·§4 모두 **생존편의 미통제**다. 상장폐지된 ETF·종목은 패널에 없다.

## 8. 게재 여부 — 싣지 않는다

사용자 지시는 "통과하면 실을 자리를 만들어서 실어달라"였다. **세 축 모두 통과하지 못했으므로
브리핑에 절을 신설하지 않는다.** 참고표로 부착할 근거도 없다 — §3 은 450일에서 부호가 없고,
§4 는 종목군이 유니버스와 겹치지 않으며, §1 의 운용사 뷰는 우리 급락 게이트보다 4거래일 느리다.

**바뀐 것은 데이터 자산뿐이다**: `krx_etf_panel.csv` 114일 → 536일, DART 지분공시 원본 201,530건,
수집기 3종(멱등). 선정 로직·브리핑 양식·아침 루틴은 변경 없음.
