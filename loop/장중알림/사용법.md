# 장중 매수·매도 알림 — 사용법 (2026-10-20)

PC가 켜져 있는 동안 평일 09:00~15:30, 20초마다 키움(조회 전용)으로 현재가를 확인해
브리핑 규칙선에 닿으면 **PC 팝업 + 카카오톡(나와의 채팅)** 으로 알립니다. 주문은 하지 않습니다.

## 처음 한 번
1. `test_alert.bat` 더블클릭 → 화면 오른쪽 아래 팝업이 뜨면 정상.
2. (카톡) `kakao_setup.py` 맨 위 설명대로 카카오 개발자 앱을 만들고 `py -3 kakao_setup.py` 실행.
3. `register_autostart.bat` 더블클릭 → 평일 08:50 에 자동으로 켜짐. (바로 쓰려면 `start_watch.bat`)

## 매일
- 아침 루틴이 `plans/watch_plan_<날짜>.json` 을 만들면 감시기가 그걸 읽습니다. 따로 할 일 없음.
- 검은 창(Intraday Alert)을 닫으면 그날 알림이 멈춥니다. 15:31 에 저절로 꺼집니다.

## 언제 무엇이 오나
| 시각 | 알림 |
|---|---|
| 09:01~ | 단기 5종 시가 판정: ① 정상 출발 → 지금 매수 / ② 갭상승 → 대기, 매수상단 터치 시 다시 알림 / ④ 갭하락 → 절반 매수 |
| 장중 | 손절선(2 ATR)·목표가(+3%) 도달 |
| 14:30 | ② 미체결 종목: 보수 모드면 '오늘 포기', 표준 모드면 15:10 에 '종가 무렵 시장가 매수' |
| 15:05 / 15:17 | 중기 5종 Rule CB 밴드 판정(예비 / 확정) → 종가 매수 대상 또는 관망 |
| 15:05~15:10 | 단기·중기 청산 대상, 트랙 D 20일 청산·종가 매수(포기선·MA20 확인) |

같은 알림은 하루 한 번만 옵니다(`plans/sent_<날짜>.json`). 규칙은 브리핑과 같고 새 신호는 없습니다.
