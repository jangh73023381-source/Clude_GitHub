## 1. 질문을 두 형태로 나눈다

사용자 질문은 한 덩어리지만 데이터로는 완전히 다른 둘이다.

- **A(top-down)**: 골드만·모건스탠리가 "4Q 반도체 업황 개선" 같은 뷰를 내는 것. 리포트 본문.
- **B(bottom-up)**: 그 뷰의 재료이자 결과인 **애널리스트 이익추정치**. 정량 시계열.

A는 2026-07-05 「뉴스 활용 원칙」에서 이미 닫힌 부류다 — *"애널리스트 리포트·웹뉴스·유튜브는
과거 시계열 재구성이 불가해 종목 선정 규칙으로 부적합"*. 이번 검토의 실질 대상은 **B**다.

## 3. 축 B — EPS 추정치 수정의 시차 구조 (★ 핵심)

신호는 **가격정규화 수정폭** `ΔEPS / 시작시점 주가`(부호 역전·0 나눗셈 회피, 실무 표준).
수익률은 21거래일(≈1개월) 단위. 스피어만, n=225.

```
[동시 k=0]
  최근1개월 수정   ↔ 최근1개월 주가        rho +0.053  p=0.426
  1~2개월전 수정   ↔ 같은기간 주가         rho +0.161  p=0.016  ★유일하게 유의
  2~3개월전 수정   ↔ 같은기간 주가         rho -0.010  p=0.878

[후행 — 주가가 먼저, 수정이 나중]
  최근1개월 수정   ↔ 1~2개월전 주가        rho +0.119  p=0.075
  1~2개월전 수정   ↔ 2~3개월전 주가        rho +0.096  p=0.149

[선행 — 수정이 먼저, 주가가 나중  ★알파가 있으려면 여기가 양수여야 한다]
  1~2개월전 수정   → 이후 1개월 주가       rho -0.047  p=0.479
  2~3개월전 수정   → 이후 1개월 주가       rho -0.111  p=0.098
  2~3개월전 수정   → 이후 2개월 주가       rho -0.044  p=0.508

[R3 정의교체 — 비율형 ΔEPS/EPS 로 다시 계산]
  1~2개월전 수정률 → 이후 1개월 주가       rho -0.004  p=0.956
```

**정점이 k=0(동시)이고, 후행(+0.119) > 선행(-0.047) 이다.**
2026-09-02 수출입 검정에서 나온 것과 **똑같은 모양**이다(수출↔주가 상관 정점 k=0, 반도체 +0.760).
펀더멘털 정보는 주가를 선행하지 않고, 애널리스트의 추정치 수정은 오히려 주가를 조금 뒤따른다.
[[attention-search-weight-rejected]]에서 검색량이 주가를 3~4거래일 후행한 것과 같은 구조다.

**5분위 단조성** — 1~2개월전 수정폭 낮음→높음, 이후 1개월 수익률:
```
평균  +3.51 / +1.76 / +1.73 / +0.07 / +3.05   (전체 +2.02%)
중앙  +1.73 / -0.88 / -2.83 / +1.50 / -0.38
Q5-Q1  -0.46%p   t=-0.18  p=0.854          → U자, 단조 아님
차년도 EPS 수정으로 바꿔도  Q5-Q1 +0.49%p  t=+0.20  p=0.841
```

**역모멘텀 통제 후 잔여 정보 = 0**:
```
단순     rv_mid → r_late        rho -0.047
신호기간 주가(r_mid) 통제 후     rho -0.004
```
수정 신호가 갖는 얼마 안 되는 관계마저 **과거 주가가 이미 설명한다.** mom20과 중복이라는 뜻이며,
이는 Rule J2(검색량 지속관심 가점) 때 확인된 캐비앳과 같다.

**커버리지 층화** — 애널리스트가 많아도 달라지지 않는다:
```
3~7명   rho +0.051 (n=83)   8~15명  rho -0.129 (n=88)   16명+  rho +0.025 (n=54)
```

## 4. 축 C — 목표주가 괴리율: 검정이 성립하지 않는다

첫 계산에서 **Q1 +9.12% vs Q5 -5.90%, t=-5.72 p=0.000** 이라는 강한 역신호가 나왔다.
**이것을 신호로 채택하면 안 된다** — 룩어헤드다.

괴리율은 `오늘 목표주가 ÷ 오늘 주가`로 계산되고, 과거 시점 목표주가는 조달되지 않는다.
따라서 "오늘의 괴리율 → 최근 1개월 수익률"은 예측이 아니라 **같은 기간을 양변에 쓴 항등에 가깝다.**

```
괴리율 ↔ 최근1개월 주가    rho -0.379
괴리율 ↔ 1~2개월전 주가    rho -0.406
괴리율 ↔ 2~3개월전 주가    rho -0.260
```

목표주가는 느리게 움직이므로 **최근 3개월간 하락한 종목일수록 괴리가 자동으로 커진다.**
괴리율은 애널리스트 정보가 아니라 **역모멘텀의 거울상**이다. 실전에서 쓰려면 목표주가의
과거 스냅샷이 필요한데 그것이 없으므로, 이 축은 **미래 시점으로만 검정 가능**하다.

## 5. 축 D — 투자의견: 횡단면 변별력 자체가 없다

```
매수(strongBuy+buy) 비율   중앙 94%   하위10% 62%
'매도'(sell+strongSell) 의견이 하나라도 있는 종목  52/225종
매수비율 5분위 → 이후 1개월:  +0.95 / -0.01 / +2.85 / +4.02 / +2.00
Q5-Q1 +1.05%p  t=+0.37  p=0.709
```

한국 시장 투자의견은 구조적 매수 편향이라 **종목을 가르는 정보가 애초에 담겨 있지 않다.**
변별을 하려면 '의견 변경(업/다운그레이드) 이벤트'를 써야 하는데, 그건 다시 §2의
시계열 재구성 불가 문제로 돌아간다.

## 6. 축 E — 섹터 집계: 무관 신호 대조군 미통과

사용자 질문의 형태 그대로다. 구성종목 EPS 수정 중앙값으로 섹터를 정렬하고, 이후 1개월
섹터 수익률(동일가중)을 본다. DART 업종 2자리, 4종목 이상 **17섹터**.

```
수정 상위      금융서비스 +0.93 → 이후 -2.16%    소매 +0.13 → -2.32%
             금융 +0.11 → +4.42%              화학 +0.07 → -0.49%
             의약품 +0.07 → -14.29%           전자부품·반도체 +0.05 → +13.09%
수정 하위      건설 -0.14 → +17.26%            자동차 -0.07 → -11.62%

섹터 수정 → 이후 섹터 수익   rho -0.204  p=0.433   (섹터 17개)
상위5섹터 -2.97%  vs  하위5섹터 +1.91%   →  스프레드 -4.88%p (방향이 반대)
```

**무관 신호 대조군 (2026-09-02 신설 관문) — 섹터 라벨 무작위 셔플 500회:**
```
관측 스프레드 -4.88%p
셔플 귀무 평균 -0.49%p, sd 2.94, 90% 구간 [-5.52, +4.55]
경험적 p(|셔플| ≥ |관측|) = 0.106
```
**관측값이 귀무 구간 안에 있다.** 섹터 17개 표본에서는 라벨을 무작위로 섞어도 ±5%p 스프레드가
흔히 나온다. [[actually-rebuttal-event-closed]]에서 셔플 귀무 평균이 0이 아니었던 것과 같은 교훈이다.

## 7. 축 A(top-down 뷰)의 표본 산술

정량화가 가능하다고 가정해도 검정이 성립하지 않는다.

- **표본**: 7년 × 분기 4회 = **28 관측**. `judge_ready.py` 의 N* 은 하한 8·상한 60이지만
  섹터 수익률 sd/|평균| 비를 넣으면 28로는 부호 판정이 안 된다.
- **시계열 재구성**: 2019년 3분기에 골드만이 반도체를 어떻게 봤는지를 **그 시점 그대로** 모을
  경로가 없다. 지금 검색되는 것은 결과를 아는 상태에서 고른 표본(사후 편의)이다.
- **공개 즉시 반영**: 발표되는 순간 모두가 안다. [[wallst-transfer-table]] 에서 확인한
  *"A 지표 초과의 89.4%가 갭"* 과 같은 구조로, 뉴스가 된 전망은 개장 갭에 들어간다.

## 8. 채택 형태 — 참고 전용에 그친다

선정 반영은 하지 않는다. 참고표로 붙일 경우의 형태:

- **위치**: [8-2] 수출입 참고표 뒤, 같은 자격(참고 전용·선정 미반영·필수 각주).
- **내용**: 그날 추천 섹터의 구성종목 EPS 컨센서스 3개월 수정률 중앙값 1줄.
- **필수 각주**: "이 수치는 예측 신호가 아니다. 2026-09-22 검정에서 추정치 수정의 **선행
  예측력은 확인되지 않았고**(선행 rho -0.047~-0.111, 전부 p>0.09), 상관 정점은 **동시(k=0)**
  였다. 역모멘텀을 통제하면 잔여 상관이 -0.004로 사라진다. 종목 선정에는 사용하지 않는다."
- **부가가치 평가**: 얇다. 수출입 표(8-2)가 이미 같은 정보를 더 이른 시점에 담고 있고
  (수출은 실적의 선행 재료, 컨센서스는 그 해석), 조회에 5분이 든다.

**추천**: 지금은 붙이지 않는다. 붙이려면 매일 5분 조회 비용과 24페이지→경량화(2026-09-12)
방향을 함께 고려해야 한다.

## 9. 한계 — 반드시 함께 적을 것

1. **1시점 횡단면이다.** 2026-09-22 하루의 스냅샷이며, 이 프로젝트 표준인 7년 시계열 검정이
   아니다. **R2(3-fold)·R5(꼬리 기여)·잭나이프를 적용할 수 없다.** 따라서 이 문서는
   "기각 확정"이 아니라 **1차 스크리닝 미통과**다.
2. **표본 국면 편중.** 최근 3개월은 반도체 주도 강세 구간이었다(전자부품·반도체 이후 +13.09%).
   다른 국면에서 같은 결과가 나온다는 보장이 없다.
3. **30/60/90일은 달력일**이고 수익률은 21거래일 근사다. 경계가 며칠 어긋난다.
4. **생존편의**: 시총 상위 416종은 2026-06-05 PIT 스냅샷이라 그 시점 기준 대형주 편향이다.
5. 커버율 77%. 응답하지 않은 96종은 커버리지가 없는 소형주 쪽에 몰려 있다.

## 10. 열지 않기로 한 것 / 재시도 금지

- **목표주가 괴리율을 신호로 쓰는 것** — §4. 시점 정합이 깨져 있고, 통과시키면 역모멘텀을
  우회 재시도하는 셈이다(Rule X/X2 위험조정 모멘텀, Rule CC 극단 반전 콤보 기각 이력).
- **투자의견 수준(level)을 점수 축에 넣는 것** — §5. 변별력이 없다.
- **유료 컨센서스 히스토리 구매(FnGuide 등)** — 이 검토 결과로는 지불 근거가 없다.
  13F·다크풀을 사지 않기로 한 것(2026-09-08 §7)과 같은 판단이다.
- **구간 경계·수정 기간(30/60/90일) 최적화** — 하는 순간 알파 축이 되어 R1~R5 + 무관 신호
