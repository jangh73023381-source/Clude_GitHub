## 실행 절차

### 0단계 — 관심 신호 처리 (신규, 자동 포함) — **두 개의 날짜를 동시에 다룬다**

장전 실행이 표준이므로 실행일 T에서 다루는 날짜가 둘이다. 혼동하지 말 것.

| 구분 | 날짜 | 하는 일 |
|---|---|---|
| **0-A 채점용** | D = T의 **직전 거래일** | `attention_shadow_picks.csv`에 `date == D` 행이 있는지 확인. 있으면 그대로 2단계 채점에 사용. 없으면 사후수집 후 `post_hoc` 표기. |
| **0-B 신규 수집** | T = **오늘** | 장전 윈도(T-1 16:00 ~ T 09:00) 안에서 오늘 신호를 수집·기록. 이 행이 **내일 루프의 채점 대상**이 된다. |

> 매일 장전에 돌리면 0-B가 다음 날의 0-A를 자동으로 채워주므로 사후수집이 발생하지 않는다.
> **연쇄가 한 번 끊기면 그날치는 영구히 사후수집으로 남는다** — 거른 날은 로그에 표시하고
> 20영업일 판정 표본에서 분리한다.

**수집 방법(0-B, 0-A 사후수집 공통)** — `attention_pilot.md` v2.3 소스 개편본:

   | 소스 | 수집 여부 | 용도 |
   |---|---|---|
   | 네이버 데이터랩 검색 | **수집** | **랭킹 축** (당일 ratio ÷ 직전 5영업일 평균 → z) |
   | 뉴스 (이벤트 키워드 쿼리) | **수집** | 악재 배제필터 전용 (감성 z) |
   | 유튜브 전체 / yt20 | **수집 안 함 (v2.3 폐지)** | — |
   | 트위터/X | 수집 안 함 (크레딧 미등록) | — |
   | DART 공시 | **매주 첫 거래일만** | 기록 전용 (5거래일 캐리) |

   - 뉴스 쿼리는 테마명 단독이 아니라 **이벤트 결합형**: `"<테마> 공급계약"`, `"<테마> 수주"`,
     `"<테마> 정부 지원"`, `"<테마> 증설"`, `"<테마> 규제"`.
     (테마명 단독은 display=100 상한에 13/15 테마가 걸려 절단편의가 생긴다 — v2.3에서 폐기.)
   - DART 주간 스캔은 `references/attention_dart_watchlist.csv`(15테마 × 3종 = 45종목)를
     opendart MCP `search_disclosures(company=…, 최근 7일)`로 조회.
     가점: 단일판매ㆍ공급계약체결 / 수주 / 공급계약 / 유형자산취득(증설) / 투자판단관련주요경영사항
     감점: 유상증자결정 / 전환사채권발행결정 / 생산중단 / 영업정지 / 중대재해발생

**사후수집 플래그**: 장전 윈도를 지난 뒤 수집한 행은 `post_hoc=1` 취지를 로그·보고서에 명시하고,
20일 판정에서 **별도 집계**한다(룩어헤드 의심 구간이므로 주 표본에서 분리).

## 표준 실행 순서 — 장전 1회 (2026-07-26 확정)

```
T-1  16:00  장 마감 → 종가 확정
─────────────────────────────────────────────────────────────
T    05:30  ① 통합 루프 시작
              0-A  D(=T-1) 관심신호 행 확인
              1~2  D 브리핑 픽 채점 (트랙 A) + 조합제 채점 (트랙 B)
              3~5  원인분석 → 개선 가설 → 검증관 (트랙 A 한정)
              6    analysis-method.md 갱신(변경 시) + 루프 보고서 .docx
     06:30  ② 0-B 오늘(T) 관심신호 수집  ← 장전 윈도 안, 09:00 전이면 OK
     07:00  ③ 데일리 브리핑 생성
              · 방금 갱신된 analysis-method.md의 '확정' 규칙만 적용
              · 단기 ETF 5종 = 트랙 A. 조합제는 참고 병기만
     09:00  ④ 장 시작 — 브리핑의 지정가 진입전략대로 매매
─────────────────────────────────────────────────────────────
T    16:00  장 마감 → 다음 날 T+1 05:30 루프의 채점 대상이 됨
```

**핵심은 ①이 ③보다 먼저**라는 것이다. 루프가 방법을 바꾸면 그날 브리핑이 즉시 새 방법을 쓰고,
안 바꾸면(대부분) 브리핑은 기존 확정방법 그대로 간다. 순서가 뒤집히면 "어제 배운 것"이 하루 늦게
반영된다.

### 장 마감 후 루프는 더 이상 돌리지 않는다
종전에는 마감 후(16:00 이후)에 루프를 돌렸으나, 그러면 (a) 그날 관심신호가 항상 사후수집이 되고
(b) 개선 결과가 다음 날 아침 브리핑까지 대기해야 한다. 장전 1회로 통일한다.

### 시간이 부족할 때 (경량 모드)
장전 시간이 빠듯하면 **3~5단계(개선 루프)만 생략**하고 0~2단계(신호·채점)와 6단계(기록)는 반드시
수행한다. 채점·신호 연쇄가 끊기면 표본이 영구 손실되지만, 개선 루프는 하루 미뤄도 복구 가능하다.
생략한 날은 로그에 "경량 모드(개선 루프 이월)"로 남기고, 이월된 개선은 다음 실행에서 함께 처리한다.

### 1단계 — 대상 수집 (기존)

`references/scripts/get_picks.py`로 fable 폴더의 최신 `데일리브리핑_*.docx`에서 단기 ETF 상위 5종을
추출해 `current-holdings.md`에 기록. 채점일 D의 16:00 이후에만 진행.

### 2단계 — 이중 채점 (확장)

```
python3 references/scripts/dual_score.py <채점일 YYYYMMDD> --picks <코드5개 콤마구분>
```

한 번 실행으로 아래를 전부 출력한다.

- **1차 지표**: 코스피 지수(^KS11) 대비 초과수익 — 픽5 동일가중·1일 보유·왕복비용 10bp 차감
- **병기**: KODEX200 대비 초과수익
- **보조**: 전체 ETF 유니버스 상위10% 이진 적중 (트랙 A만)
- **트랙 B**: 조합제 픽 5종·초과수익, `combo_shadow_tracker.csv`에 멱등 1행 누적
- **참고**: 15섹터 등가중 기준선 (트랙 B의 진짜 기준선 — 코스피가 아니다)

가격 데이터가 없으면 키움 REST 일봉으로 먼저 수집하고 `backtest/panel_close_*.csv`를 갱신한다.
코스피 종가는 yfinance `^KS11` → `backtest/kospi_close.csv`에 append.

### 3~5단계 — 원인 분석 · 검증 루프 · 검증관 (기존, **트랙 A 한정**)

- 기존 절차 그대로: 불가항력/학습가능 분류(v2.2 A) → distinct 가설 백테스트(과최적화 가드
  full·train·test 3분할) → `loop-goal-verifier` V1~V5 → FAIL 시 3단계 반송(최대 10회).
- **트랙 B는 이 단계에 넣지 않는다.** 조합제 파라미터(mom20 하위컷 상위10위 / 감성컷 -0.15 /
  픽 5종)는 20일 판정 전까지 동결.
- N 대장·워크포워드 트래커 갱신도 트랙 A 기준으로만 한다.

### 6단계 — 보고서 (확장)

`report-format.md` 표준 양식에 **(A2) 조합제 shadow 병기** 섹션을 추가한다.

```
(A)  현 추천 채점 — 트랙 A(확정방법)
(A2) 조합제 shadow 병기 — 트랙 B          ← 신규
     · 같은 날 두 트랙의 코스피 대비 초과수익·승패 나란히
     · 조합제 누적 N일 / 평균 초과 / 코스피 이김 / 15섹터 기준선 대비
     · 20영업일 판정까지 남은 일수, 사후수집 일자 수
Reference · 원인 분석 · (B) 검증 루프 · 방법 변경 · 최종 채택 · 면책
```

최종 산출물은 **반드시 `.docx`** (`[2026-07-10 추가]` 규칙) 로 만들어 `present_files`로 공유한다.

## 조합제 승격 판정 (≈2026-08-21)

20영업일 누적 도달 시 아래 **세 조건 동시 충족**일 때만 데일리 브리핑 편입을 검토한다.

1. 코스피 지수 대비 평균 초과수익 **> 0**
2. **15섹터 등가중 기준선 초과** — 코스피만 이기는 건 섹터 베타 틸트일 수 있다(10일 표본에서
   등가중 바스켓 자체가 코스피를 +0.368%p/일 이겼다)
3. 잭나이프(하루씩 제거) **하한 > 0** — 특정 하루에 기대지 않을 것

미달 시 현행 확정방법 유지. **판정 전까지 실제 추천은 트랙 A만 사용한다.**
